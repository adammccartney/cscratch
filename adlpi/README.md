## Build dependencies

In particular, librt is important for message queues.

Debian, Ubuntu, and similar distributions:

        libcap-dev
        libacl1-dev
        libselinux1-dev
        libseccomp-dev
        gcc-multilib

RPM-based distributions (Fedora, OpenSUSE, CentOS, etc.):

        libcap-devel
        libacl-devel
        libselinux-devel
        libseccomp-devel
